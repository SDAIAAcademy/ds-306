Lab 4.1, step 1

The schema says what a valid answer is before any model answers

class Inspection(BaseModel):
    model_config = ConfigDict(extra="forbid")
    district: Optional[Literal[CODES]] = None
    inspection_date: Optional[date] = None      # and a 2026 check
    defect_type: Optional[Literal[DEFECTS]] = None
    severity: Optional[Literal["low", "medium", "high", "critical"]] = None
    hazard_to_public: Optional[bool] = None
    repair_deadline_days: Optional[int] = Field(None, ge=1, le=90)

Every field is optional because a report may not state it: the schema must allow an honest empty. Pydantic is one choice; JSON Schema, which OpenRouter's structured outputs accept for models that support them, is another. The class produces the JSON Schema, so either way it is written once. Sources: Pydantic documentation.

A colleague proposes a new quarterly figure: the share of complaints in each of the five clusters, named from their top terms. What is the main problem?

Corrected count = model's count − complaints × rectifier, summed over varieties.

The rectifier is the core of prediction-powered inference (Angelopoulos, Bates, Fannjiang, Jordan and Zrnic, Science, 2023): the model labels everything, a human sample measures its bias. Stratifying by variety is the course's choice because the bias differs by variety. The variety is guessed on the gold set too, so strata match. Sources: Prediction-powered inference.

Checkpoint

Why stratify the correction by variety?

One rectifier for all complaints (−0.030) raises every district's rate by about the same amount, 5.4 to 5.8 per 10,000. The stratified rectifiers raise Al-Naseem by 10.1 and Al-Khalij by 0.0. Which reason justifies stratifying?

It always gives narrower intervals
It uses more gold complaints
It makes all districts' rates rise equally
The model's error differs by variety and districts differ in their variety mix
Why. A single rectifier spreads the Gulf under-count over every district; stratifying puts it where the Gulf complaints are.

Answer: the fourth option. Follow up: what would make the stratified correction wrong? A district whose Gulf speakers write differently from the gold set's.

Day 4 · wrap-up

Three things to keep

Valid is not right

A schema checks form; field-level precision and recall check truth.

A cluster is a lens

It shows what the vectors see, here language and a campaign, not a category.

Correct, then compare

A human sample turns a biased count into an estimate with an interval.

Ask: which correction from today would change a decision at Sada? Usually the district comparison.
