# Brief: Nadwa Public Libraries Network

Nadwa's director wants the share of feedback about facilities in each branch, corrected for the labelling model's errors, before deciding which two branches get the renovation budget.

Files: documents.csv (2,575 documents as received, with personal data), gold.csv (200 redacted documents, two coders and the adjudicated label), model_runs_gold.csv (two prompts, three runs; synthetic), model_labels_all.csv (prompt 1, run 1, all documents; synthetic).
